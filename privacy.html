Privacy Policy — Shorts Publisher

Last updated: 2026-09-25

What the app accesses

With the account owner's consent (Google OAuth), the app uses these scopes on the owner's own YouTube channels: youtube.upload, youtube.force-ssl, youtube.readonly and yt-analytics.readonly. They are used only to upload, schedule and edit the owner's videos and to read the owner's channel statistics.

Storage

OAuth tokens and data returned by the APIs are stored only on the operator's own computer. Nothing is sent to third-party servers, sold, shared or used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see also the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Local data can be deleted on request.
